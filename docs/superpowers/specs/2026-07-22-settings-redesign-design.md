## 1. 問題

使用者反映設定介面「東西太多、很亂」。實際盤點（sol-report-04）確認：

- 目前結構是「首頁 → 點卡片 → 進子頁 → 返回」，多一層點擊。
- 真正肥的是「**資料與工具**」子頁：一頁塞 **8 個小段、15 個項目**，像雜物抽屜。
- 部分文案技術腔重、看不懂（如「加速三無的認證欄位處理」「定點絕時自動標頭目」）。
- 視覺上間距擠、段落不分明。
- beta-only 診斷項目（3 個）混在正式項目裡。

## 2. 目標（DoD）

- 頂部三分頁（資料 / 工具 / 通用設定）直接切換，移除「首頁卡片 → 子頁 → 返回」那一層。
- 每一分頁內項目數量與段落清楚、間距拉開。
- 看不懂的文案改成白話（品牌詞保留）。
- 正式版不顯示 beta-only 診斷項目。
- **不改任何設定的實際行為 / callback 邏輯**，只動 UI 結構、分組、文案、樣式。
- 全套測試維持綠；升 beta 版號；build 出 artifact 供使用者實機驗收。

## 6. 視覺調整原則

- 分頁 segmented control 常駐頂部，當前頁高亮。
